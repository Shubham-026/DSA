# DSA Practice Repository

This project contains all of my Data Structures and Algorithms practice programs. It is organized by topic and designed to help track progress through problem-solving, implementation, and review.

## Contents

- `arrays/` - Array-based problems and solutions
- `linked-lists/` - Singly/doubly linked list implementations and exercises
- `stacks-queues/` - Stack and queue problems
- `trees/` - Binary trees, BSTs, traversal and related algorithms
- `graphs/` - Graph traversal, shortest paths, and graph algorithms
- `sorting-searching/` - Sorting algorithms and search techniques
- `dynamic-programming/` - Dynamic programming problems and solutions
- `misc/` - Other algorithm practice and utility code

## How to Use

1. Pick a topic folder.
2. Open a problem file or add a new one.
3. Implement the solution in your preferred language.
4. Test and review the code.

## Goals

- Build a strong foundation in common data structures
- Practice algorithmic problem solving
- Develop clean, reusable code
- Track learning progress over time

## Notes

- Keep solutions well-documented.
- Use meaningful file and function names.
- Add sample input/output or test cases when possible.
